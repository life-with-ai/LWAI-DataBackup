## Совместимость

- Windows x64;
- совместимый установленный .NET Framework;
- проверено на Windows 10 x64, OS build 19045;
- поддержка других выпусков Windows и точная минимальная версия .NET Framework пока не заявляются.

EXE не имеет цифровой подписи. Windows может показать стандартное предупреждение для загруженного приложения.

## Возможности версии

- копирование выбранной папки в отдельный каталог;
- создание ZIP-архива выбранной папки;
- исключение папок и файлов по настраиваемым wildcard-маскам;
- управление включением архивных файлов в резервную копию;
- предварительный подсчёт файлов и общего объёма;
- отображение прогресса, текущего файла и журнала операции;
- сохранение локальных настроек рядом с portable EXE;
- открытие результата после завершения операции.

Сверь SHA-256 перед распаковкой и проверь результат на некритичных данных перед использованием с важными файлами.
