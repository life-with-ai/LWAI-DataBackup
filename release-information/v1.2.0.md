# LWAI-DataBackup v1.2.0

## Файлы

- Portable ZIP: LWAI-DataBackup-1.2.0-windows-x64-portable.zip
- SHA-256: 6DC79B017013E2019C9263F3FA4A246807CF283C3BAC80FD3B39F7557445EAD5
- Checksum sidecar: LWAI-DataBackup-1.2.0-windows-x64-portable.zip.sha256

## Совместимость

- проверенные системы: Windows 8.1 x64 и Windows 10 x64;
- совместимый установленный .NET Framework.

EXE не имеет цифровой подписи. Windows может показать стандартное предупреждение для загруженного приложения.

## Изменения

- укреплена защита исходных данных и целостности готового результата;
- незавершённые copy и ZIP используют уникальный `.partial`, который публикуется только после полной проверки;
- остановка завершает задание, а следующий запуск начинается заново с актуального источника;
- унифицированы имена файловой копии и ZIP с безопасными суффиксами при совпадении;
- обновлены рекомендуемые исключения и управление папками backup и backups;
- добавлены опциональный технический журнал, сохранение окна и очистка отображаемого журнала;
- улучшены структурированный журнал, состояния операции, прокрутка списков и открытие результата.

Сверь SHA-256 перед распаковкой и проверь результат на некритичных данных перед использованием с важными файлами.
