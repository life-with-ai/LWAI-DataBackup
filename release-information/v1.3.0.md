## Совместимость

- проверенные системы: Windows 8.1 x64 и Windows 10 x64;
- совместимый установленный .NET Framework.

EXE не имеет цифровой подписи. Windows может показать стандартное предупреждение для загруженного приложения.

## Изменения

- исправлена задержка предварительного анализа крупных проектов, в том числе при наличии исключённых каталогов;
- исключения применяются до обхода исключённого содержимого;
- добавлено предварительное предупреждение о путях, превышающих стандартный предел Windows;
- операцию можно отменить до создания результата либо продолжить без перечисленных объектов;
- завершение с пропусками отображается отдельно и содержит количество пропущенных файлов и каталогов;
- файловая копия и ZIP используют сокращённый шаблон имени результата;
- интерфейс сохраняет отзывчивость при обработке большого количества файлов и показывает активность во время финальной проверки.

Сверь SHA-256 перед распаковкой и проверь результат на некритичных данных перед использованием с важными файлами.
