## Совместимость

- проверенные системы: Windows 8.1 x64 и Windows 10 x64;
- совместимый установленный .NET Framework.

EXE не имеет цифровой подписи. Windows может показать стандартное предупреждение для загруженного приложения.

## Изменения

- добавлены локальные профили со своими путями, режимом, исключениями и опциями;
- профиль можно создать пустым либо на основе сохранённых настроек существующего профиля;
- пользовательские профили можно выбрать, переименовать, удалить и расположить в нужном порядке;
- ручное сохранение относится только к активному профилю, а дополнительное автосохранение включается отдельно;
- автосохранение текстовых полей выполняется после потери фокуса либо через 5 секунд после последнего изменения;
- последний выбранный профиль восстанавливается при следующем запуске;
- добавлено отдельное окно с поддерживаемыми горячими клавишами;
- проектные диалоги позволяют перемещать и сворачивать главное окно.

Сверь SHA-256 перед распаковкой и проверь результат на некритичных данных перед использованием с важными файлами.
