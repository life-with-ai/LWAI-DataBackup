# Changelog

[Русский](#русский) | [English](#english)

## Русский

### 1.6.0

#### Изменено

- Проверка доступности исходной и целевой папок выполняется только для текущего задания после нажатия `Старт` и не блокирует интерфейс во время ожидания сетевого пути.
- Сохранение профилей, глобальных настроек и положения окна больше не проверяет доступность записанных исходных папок.
- Файл профилей и глобальных настроек теперь называется `config.json`.

#### Исправлено

- Клавиши ← и → в поле имени нового профиля перемещают текстовый курсор и не переключают сохранённые профили.

### 1.5.0

#### Добавлено

- Светлая и тёмная темы приложения.
- Русский и английский интерфейс с сохранением выбранного языка.
- Единое окно глобальных настроек для темы, языка, автосохранения и отображения дополнительных параметров.

#### Изменено

- Переключение темы и языка применяется сразу к открытому главному окну и проектным диалогам.
- Команда ручного сохранения активного профиля называется `Сохранить профиль`.
- Автосохранение настраивается в окне глобальных настроек.

## 1.4.0

### Добавлено

- Локальные профили со своими путями, режимом, исключениями и опциями резервного копирования.
- Создание пустого профиля либо профиля на основе сохранённых настроек существующего профиля.
- Выбор, переименование, удаление и изменение порядка пользовательских профилей.
- Выключенное по умолчанию автосохранение профиля после потери фокуса либо через 5 секунд после последнего изменения текста.
- Отдельное окно с поддерживаемыми горячими клавишами.

### Изменено

- Последний выбранный профиль восстанавливается при следующем запуске приложения.
- Профиль «По умолчанию» содержит обновлённый начальный список рекомендуемых исключений.
- Проектные диалоги позволяют перемещать, сворачивать и восстанавливать главное окно.

### Исправлено

- Исправлено восстановление выбранного профиля после повторного запуска приложения.

## 1.3.0

### Добавлено

- Предварительное предупреждение о путях, превышающих стандартный предел Windows, с точным расположением объекта и минимальным сокращением пути.
- Возможность отменить операцию до создания результата или продолжить без перечисленных объектов.
- Отдельное завершение с пропусками и количеством пропущенных файлов и каталогов.

### Изменено

- Исключения папок и файлов применяются до обхода исключённого содержимого.
- Интерфейс сохраняет отзывчивость при анализе и обработке большого количества файлов.
- Файловая копия и ZIP используют сокращённый шаблон имени `<проект>-ГГГГ-ММ-ДД-ЧЧММСС` с безопасным суффиксом при совпадении.
- После достижения 100% текущий этап проверки отображается рядом с индикатором активности, а полоса возвращается в исходное состояние после завершения.

### Исправлено

- Исправлена задержка предварительного анализа крупных проектов, в том числе при наличии исключённых каталогов.

## 1.2.0

### Добавлено

- Отключённый по умолчанию технический журнал одной сессии приложения.
- Сохранение допустимых размеров и положения главного окна.
- Команда очистки отображаемого журнала без удаления технических log-файлов.

### Изменено

- Укреплена защита исходных данных и проверка целостности резервной копии до публикации готового результата.
- Незавершённый результат создаётся как `.partial` и получает готовое имя только после полного успеха.
- Остановка завершает текущее задание без режима паузы, а следующий запуск начинается заново с актуального источника.
- Файловая копия и ZIP используют единый шаблон имени с безопасными суффиксами при совпадении.
- Обновлены рекомендуемые исключения и управление включением папок backup и backups.
- Журнал разделён на колонку времени и переносимый текст; состояния операции и недоступные параметры получили более спокойное оформление.
- Главное окно поддерживает стандартную максимизацию и восстанавливает допустимые размеры и положение.

### Исправлено

- Опасные пересечения source и destination, reparse-компоненты путей и размещение данных приложения внутри источника блокируются до записи.
- Изменение, исчезновение или недоступность обязательного файла больше не приводит к публикации готового результата.
- Исправлены видимость последней строки и прокрутка многострочных списков и журнала.
- Быстрые повторные нажатия команды `Результат` больше не открывают несколько окон Проводника одновременно.

## 1.1.0

### Изменено

- Переработан интерфейс основного окна и унифицировано визуальное оформление элементов управления.
- Команды сохранения настроек, выхода, управления дополнительными параметрами и просмотра сведений о программе организованы в главном меню.
- Обновлены окно выбора папки, окно «О программе» и уведомление о сохранении настроек.
- Управление активной операцией отображает состояния запуска, отмены и завершения отмены; параметры задания блокируются на время обработки.
- Основные элементы остаются доступными при допустимом уменьшении окна, а полосы прокрутки появляются только при переполнении содержимого.

### Исправлено

- Раскрытый список режима закрывается при щелчке вне списка.
- Ошибки исходного пути и назначения отображаются рядом с соответствующим полем до запуска операции.

## 1.0.0

### Добавлено

- Копирование выбранной папки в отдельный каталог.
- Создание ZIP-архива выбранной папки.
- Исключение папок и файлов по настраиваемым wildcard-маскам.
- Управление включением архивных файлов в резервную копию.
- Предварительный подсчёт файлов и общего объёма.
- Отображение прогресса, текущего файла и журнала операции.
- Сохранение локальных настроек рядом с portable EXE.
- Открытие результата после завершения операции.

## English

### 1.6.0

#### Changed

- Source and destination availability is checked only for the current task after `Start`, without blocking the interface while a network path responds.
- Saving profiles, global settings, and window position no longer checks whether stored source folders are available.
- The profiles and global settings file is now named `config.json`.

#### Fixed

- The ← and → keys move the text cursor in the new profile name field instead of switching saved profiles.

### 1.5.0

#### Added

- Light and dark application themes.
- Russian and English interfaces with persistence of the selected language.
- One global settings dialog for theme, language, autosave, and the visibility of additional options.

#### Changed

- Theme and language changes are applied immediately to the open main window and project dialogs.
- The command for manually saving the active profile is named `Save profile`.
- Autosave is configured in the global settings dialog.
