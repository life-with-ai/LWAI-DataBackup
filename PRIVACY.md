# Политика конфиденциальности / Privacy Policy

[Русский](#русский) | [English](#english)

## Русский

Дата вступления в силу: 13 августа 2026 года.

### Общие положения

`DataBackup – Life with AI` – локальное portable Windows-приложение для копирования или ZIP-архивации выбранной папки с управляемыми исключениями.

### Обрабатываемые данные

- выбранные пользователем пути источника и назначения;
- имена каталогов и файлов, размеры и содержимое файлов, включённых в задание;
- правила исключения, выбранный режим copy или ZIP и другие параметры операции;
- глобальные настройки темы, языка, автосохранения и отображения дополнительных параметров;
- технический журнал хода и результата операции;
- локальные профили и настройки рядом с EXE в `config.json`.

### Локальное хранение и передача

Результат сохраняется только в выбранном пользователем месте назначения. Локальная конфигурация и журнал находятся на устройстве пользователя. Пользователь самостоятельно управляет конфигурацией, журналами и созданными резервными копиями. Удаление приложения не удаляет автоматически созданные copy-каталоги или ZIP-архивы.

Приложение не использует телеметрию, внешний API, облачную синхронизацию, серверную проверку лицензии или внешний crash-reporting и не передаёт пользовательские данные разработчику. Сетевой путь используется только по прямому выбору пользователя как источник или место назначения в пределах файловых разрешений Windows.

### Безопасность

Не публикуйте в публичных каналах поддержки реальные пользовательские данные, конфиденциальные сведения, токены, ключи, приватные пути или иные чувствительные данные. Правила сообщения об уязвимостях приведены в [SECURITY.md](SECURITY.md), правила получения поддержки – в [SUPPORT.md](SUPPORT.md).

## English

Effective date: August 13, 2026.

### General

`DataBackup – Life with AI` is a local portable Windows application for copying a selected folder or creating a ZIP archive with configurable exclusions.

### Data processed

- source and destination paths selected by the user;
- directory and file names, sizes, and contents of files included in a task;
- exclusion rules, the selected copy or ZIP mode, and other operation settings;
- global theme, language, autosave, and additional-options visibility settings;
- the technical log of operation progress and results;
- local profiles and settings stored next to the EXE in `config.json`.

### Local storage and transfer

The result is stored only in the destination selected by the user. The local configuration and log remain on the user's device. The user controls the configuration, logs, and created backups. Removing the application does not automatically delete copy directories or ZIP archives created by it.

The application does not use telemetry, an external API, cloud synchronization, server-side license checks, or external crash reporting, and it does not send user data to the developer. A network path is used only when the user explicitly selects it as a source or destination and only within Windows file permissions.

### Security

Do not publish real user data, confidential information, tokens, keys, private paths, or other sensitive information in public support channels. See [SECURITY.md](SECURITY.md) for vulnerability reporting and [SUPPORT.md](SUPPORT.md) for support requests.
