# Политика конфиденциальности DataBackups

Дата актуализации: 13 августа 2026 года.

## Общие положения

`DataBackups` является локальным portable Windows-приложением. По подтверждённой текущей модели приложение не использует телеметрию, внешний API, облачную синхронизацию, серверную проверку лицензии и внешний crash-reporting.

## Обрабатываемые данные

Для выполнения резервного копирования приложение локально обрабатывает выбранные пользователем пути, имена каталогов и файлов, размеры, правила исключений, журнал операции и содержимое файлов, которые пользователь включил в задание. Настройки сохраняются рядом с EXE в локальном `data-backups.config.json`.

Приложение не должно включать реальные пользовательские пути, конфигурации, сетевые адреса и содержимое резервируемых файлов в публичный Git или официальный Release package.

## Передача данных

Подтверждённой функции передачи пользовательских данных разработчику либо третьим лицам нет. Сетевой путь может использоваться самим пользователем как источник или место назначения; такая работа выполняется в пределах выбранного пользователем файлового доступа Windows.

## Удаление локальных данных

Пользователь управляет локальным config, журналами и созданными резервными копиями самостоятельно. Удаление приложения не удаляет созданные им backup-каталоги или ZIP автоматически.

## Безопасность

Перед публикацией каждого Release проверяется отсутствие секретов, реальных пользовательских конфигураций и приватных путей. Сообщения о возможной утечке данных следует направлять по безопасному каналу, указанному в `SECURITY.md`, не прикладывая реальные резервируемые файлы.
