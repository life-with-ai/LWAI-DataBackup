# Поддержка / Support

[Русский](#русский) | [English](#english)

## Русский

Сообщения об ошибках и предложения функций принимаются через [GitHub Issues](https://github.com/life-with-ai/LWAI-DataBackup/issues).

В сообщении об ошибке укажите версию LWAI-DataBackup, версию и архитектуру Windows, последовательность воспроизведения, ожидаемый и фактический результат и текст сообщения об ошибке.

Используйте только синтетические примеры. Не публикуйте реальные документы, персональные данные, приватные каталоги, токены, ключи или иные конфиденциальные сведения.

Предложение функции должно описывать пользовательскую задачу, ожидаемый результат и сценарий использования. Публикация предложения не означает обязательство реализовать его или включить в определённую версию.

Сведения об уязвимостях не публикуются в Issues; используйте порядок из [SECURITY.md](SECURITY.md).

Исходный код приложения не публикуется. Pull requests с изменениями программного кода не принимаются. Условия использования определены в [LICENSE](LICENSE).

## English

Bug reports and feature requests are accepted through [GitHub Issues](https://github.com/life-with-ai/LWAI-DataBackup/issues).

A bug report should include the LWAI-DataBackup version, Windows version and architecture, reproduction steps, expected and actual results, and any displayed error message.

Use synthetic examples only. Do not publish real documents, personal data, private directories, tokens, keys, or other confidential information.

A feature request should describe the user problem, expected result, and use case. Submitting a request does not create a commitment to implement it or include it in a particular version.

Do not report vulnerabilities in Issues; follow [SECURITY.md](SECURITY.md).

The application source code is not published. Pull requests that change application code are not accepted. Terms of use are defined in [LICENSE](LICENSE).
