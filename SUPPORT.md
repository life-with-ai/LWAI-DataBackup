# Поддержка Data Backup — Life with AI

Актуальные способы связи с Life with AI публикуются на [life-with-ai.ru](https://life-with-ai.ru). Публичный GitHub-канал проекта указывается только после его фактического создания.

## Сообщения об ошибках

В сообщении об ошибке необходимо указать:

1. версию `Data Backup — Life with AI`;
2. версию и архитектуру операционной системы;
3. последовательность действий для воспроизведения;
4. ожидаемый результат;
5. фактический результат;
6. текст сообщения об ошибке, если оно отображается.

Для примеров следует использовать только синтетические данные. Не допускается публиковать реальные пользовательские данные, персональные данные, приватные каталоги, токены, ключи и иные конфиденциальные сведения.

## Предложения функций

Предложение должно описывать пользовательскую задачу, ожидаемый результат и предполагаемый сценарий использования. Публикация предложения не означает обязательство реализовать его или включить в определённую версию.

## Уязвимости

Сведения об уязвимостях не следует размещать в публичных Issues. Для таких сообщений используется порядок, установленный в [SECURITY.md](SECURITY.md).

## Границы поддержки

Исходный код приложения не публикуется. Pull requests с изменениями программного кода не принимаются. Условия использования определены в [LICENSE](LICENSE).
