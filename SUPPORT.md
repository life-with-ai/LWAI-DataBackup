# Поддержка Data Backup – Life with AI

Ошибки и предложения функций принимаются через [GitHub Issues](https://github.com/life-with-ai/LWAI-DataBackup/issues).

## Сообщение об ошибке

Укажи:

1. версию LWAI DataBackup;
2. версию и архитектуру Windows;
3. последовательность воспроизведения;
4. ожидаемый и фактический результат;
5. текст сообщения об ошибке.

Используй только синтетические примеры. Не публикуй реальные документы, персональные данные, приватные каталоги, токены, ключи и другие конфиденциальные сведения.

## Предложение функции

Опиши пользовательскую задачу, ожидаемый результат и сценарий использования. Публикация предложения не означает обязательство реализовать его или включить в определённую версию.

Сведения об уязвимостях не публикуются в Issues; используй порядок из [SECURITY.md](SECURITY.md).

Исходный код приложения не публикуется. Pull requests с изменениями программного кода не принимаются. Условия использования определены в [LICENSE](LICENSE).
