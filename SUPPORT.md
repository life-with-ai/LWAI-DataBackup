# Поддержка DataBackups

Дата актуализации: 13 августа 2026 года.

## Сообщения об ошибках

После появления официального GitHub-репозитория сообщения об ошибках можно будет создавать в его Issues. Указывай версию приложения, версию Windows, выбранный режим copy или ZIP, ожидаемое и фактическое поведение и обезличенный фрагмент журнала. Не публикуй реальные пути, сетевые адреса, конфигурации, секреты и содержимое резервируемых файлов.

## Предложения функций

Предложения следует описывать через пользовательский сценарий: какую задачу нужно решить, какое поведение ожидается и какие ограничения важны. Расписание, автозапуск и поведение выключения компьютера требуют отдельного проектирования и тестирования и не считаются подтверждёнными возможностями текущего Release.

## Уязвимости

Потенциальные уязвимости и случаи раскрытия данных нельзя публиковать вместе с чувствительными материалами. После создания официального репозитория следует использовать private vulnerability reporting или GitHub Security Advisories, если соответствующая функция будет включена. Подробная область внимания приведена в `SECURITY.md`.

## Границы поддержки

Поддерживается только неизменённое приложение, полученное из официального GitHub-репозитория проекта либо с [life-with-ai.ru](https://life-with-ai.ru). Модифицированные, перепакованные и размещённые третьими лицами копии не поддерживаются и запрещены лицензией. Фактическая совместимость с конкретными версиями Windows объявляется только после проверки соответствующего Release.
