## Сообщение об уязвимости

Актуальные способы конфиденциальной связи с Life with AI публикуются на [life-with-ai.ru](https://life-with-ai.ru). Публичный GitHub security channel указывается только после фактического создания репозитория и включения соответствующей возможности.

Уязвимость не следует публиковать в обычном Issue, Discussion или другом открытом канале до завершения согласованного раскрытия.

## Состав сообщения

Сообщение должно содержать:

1. версию `Data Backup — Life with AI`;
2. версию и архитектуру операционной системы;
3. описание наблюдаемого поведения и потенциального воздействия;
4. безопасную последовательность воспроизведения;
5. сведения о том, воспроизводится ли проблема на синтетических данных.

Не допускается прикладывать реальные пользовательские данные, персональные данные, приватные каталоги, токены, ключи или иные конфиденциальные сведения.

## Область особого внимания

- удаление или изменение исходных данных;
- неверное сообщение об успехе после частичной операции;
- обход правил исключения;
- запись результата за пределами выбранного назначения;
- раскрытие путей или содержимого файлов в журналах;
- неожиданная сетевая активность;
- выключение компьютера после ошибочной или незавершённой операции;
- попадание приватных данных в публичный Git или Release package.

Приложение работает локально без телеметрии, внешнего API, облачной синхронизации, серверной проверки лицензии и внешнего crash-reporting. Сетевой путь используется только по прямому выбору пользователя в пределах файловых разрешений Windows.
