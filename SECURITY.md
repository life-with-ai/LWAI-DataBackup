# Политика безопасности

## Поддерживаемые версии

Поддерживаемого публичного Release пока нет.

## Сообщение об уязвимости

После создания GitHub-репозитория используй private vulnerability reporting или GitHub Security Advisories, если функция доступна. Не публикуй реальные пользовательские каталоги, конфигурации, сетевые пути или содержимое резервируемых файлов.

Особенно важны сообщения о:

- удалении или изменении исходных данных;
- неверном сообщении об успехе после частичного бэкапа;
- обходе правил исключения;
- записи результата за пределами выбранного назначения;
- раскрытии путей или содержимого файлов в логах;
- неожиданной сетевой активности;
- ошибочном выключении компьютера;
- попадании приватных данных в Git или Release.
