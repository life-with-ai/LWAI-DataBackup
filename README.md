# DataBackups

`DataBackups` — небольшое portable Windows-приложение для копирования или ZIP-архивации выбранного каталога с настраиваемыми исключениями.

Проект готовится к первому публичному выпуску готового приложения. Публично распространяется только принятая portable-сборка; исходный код и внутренние build-материалы в этот репозиторий не входят.

## Возможности текущей реализации

- копирование каталога в отдельную backup-папку;
- создание ZIP;
- исключение папок и файлов по wildcard-маскам;
- включение или исключение архивных материалов;
- предварительный подсчёт файлов и объёма;
- progress bar, текущий файл и журнал;
- сохранение настроек рядом с portable EXE;
- открытие результата.

Опция выключения ПК присутствует в коде, но пользователь сообщил о проблеме на Windows 8.1. До исправления и повторного теста она не считается надёжной. Расписание и автозапуск пока не реализованы.

## Portable-модель

Планируемый пользовательский артефакт — ZIP из GitHub Release. После распаковки пользователь запускает EXE из корня portable-папки. Среда разработки для запуска не требуется; рядом поставляются только фактически необходимые файлы.

EXE, DLL, локальный config, portable-папка и ZIP не входят в обычную Git-историю. После отдельного подтверждения проверенный пакет публикуется как GitHub Release asset из принятого архива проекта.

## Сборка

Внутренняя сборка выполняется в закрытом source-контуре проекта. До первого Release portable-пакет и заявленная совместимость должны быть повторно проверены. Публикация не пересобирает приложение: она использует только заранее принятый пакет из `backups/releases/<version>/`.

## Приватность

Приложение работает локально. Телеметрия, внешние API и облачная синхронизация не предусмотрены. Не публикуй реальные пользовательские конфигурации и пути.
