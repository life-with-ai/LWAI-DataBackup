# Data Backup – Life with AI

LWAI DataBackup 1.1.0 – локальное portable Windows-приложение для копирования или ZIP-архивации выбранной папки с управляемыми исключениями.

## Скачать

Официальные assets версии:

- LWAI-DataBackup-1.1.0-windows-x64-portable.zip;
- LWAI-DataBackup-1.1.0-windows-x64-portable.zip.sha256.

Скачивай оба файла на странице [GitHub Releases](https://github.com/life-with-ai/LWAI-DataBackup/releases), сверяй SHA-256, распаковывай ZIP в отдельную папку и запускай LWAI-DataBackup.exe.

EXE не имеет цифровой подписи. Windows может показать стандартное предупреждение для загруженного приложения.

## Основные возможности

- выбор исходной папки и папки назначения, включая доступные сетевые пути;
- создание отдельной копии каталога или ZIP-архива;
- исключение каталогов и файлов по wildcard-маскам;
- отдельное управление включением архивных материалов;
- предварительный подсчёт файлов и общего объёма;
- отображение прогресса, текущего файла, журнала и результата;
- управляемая отмена активной операции;
- сохранение локальных настроек рядом с portable EXE;
- открытие результата после завершения операции.

## Системные требования

- Windows x64;
- совместимый установленный .NET Framework;
- запись в папку приложения для локального config и права чтения/записи для выбранных каталогов.

## Прерывание и сохранность данных

Исходная папка используется только для чтения. При обработанной приложением отмене собственный незавершённый `.partial` удаляется из папки назначения. Аварийное завершение процесса, Windows или питания может оставить неполный `.partial` только в назначении; после этого резервное копирование следует запустить заново.

## Безопасность результата

- совпадающее или вложенное назначение отклоняется;
- junction, symbolic link и другие reparse points не обходятся как обычные элементы источника;
- существующий результат не перезаписывается;
- незавершённая операция не выдаётся за успешный финальный результат.

## Приватность

Приложение работает локально без телеметрии, внешнего API, облачной синхронизации, серверной проверки лицензии и внешнего crash-reporting. Сетевой путь используется только по прямому выбору пользователя в пределах файловых разрешений Windows.
