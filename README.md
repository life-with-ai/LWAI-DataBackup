# Data Backup — Life with AI

Локальное portable Windows-приложение для копирования или ZIP-архивации выбранной папки с управляемыми исключениями.

## Основные возможности

- выбор исходной папки и папки назначения, включая доступные сетевые пути;
- создание отдельной копии каталога или ZIP-архива;
- исключение каталогов и файлов по wildcard-маскам;
- отдельное управление включением архивных материалов;
- предварительный подсчёт файлов и общего объёма;
- отображение прогресса, текущего файла, журнала и результата;
- сохранение локальных настроек рядом с portable EXE;
- открытие результата после завершения операции.

Функции расписания и автозапуска не входят в текущую реализацию. Опциональное выключение компьютера не считается готовой возможностью до исправления и повторной проверки.

## Системные требования

- desktop Windows;
- основные функции фактически использовались на Windows 8.1 и Windows 10, но release-матрица совместимости ещё не принята;
- Windows 11 является целевой системой и должна быть проверена до заявления о поддержке;
- точная минимальная версия системного .NET Framework определяется clean-machine проверкой первой принятой сборки.

## Portable-запуск

До первого подтверждённого выпуска публичного архива нет. После принятия версии пользователь скачивает ZIP из официального источника, распаковывает его в отдельную папку и запускает `LWAI-DataBackup.exe` без установки среды разработки.

Локальная конфигурация создаётся рядом с EXE и не должна содержаться в исходном portable ZIP с чужими пользовательскими путями.

## Безопасность и приватность

Приложение работает локально. Телеметрия, внешний API, облачная синхронизация, серверная проверка лицензии и внешний crash-reporting отсутствуют. Сетевой путь используется только по прямому выбору пользователя как источник или место назначения в пределах файловых разрешений Windows.

- Исходные данные не должны изменяться во время создания копии или ZIP.
- Пользователь самостоятельно управляет локальной конфигурацией, журналами и созданными резервными копиями.
- Реальные пути, конфигурации, сетевые адреса, секреты и содержимое резервируемых файлов не должны публиковаться в Git, Release или открытых обращениях поддержки.
